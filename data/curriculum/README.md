# 교육과정표 원본

여기에 학교에서 받은 교육과정표 원본을 그대로 넣는다. 형식은 PDF · xlsx · csv · hwp 무엇이든 괜찮다.

파일명은 `연도_설명.확장자` 로:
- 2021_교육과정.pdf
- 2022_교육과정.xlsx
- ...
- 2026_교육과정.pdf

전 학과가 한 파일에 있어도 된다. 인공지능공학부(인공지능공학전공) 부분을 찾아
`src/data/curriculum.js` 형식(학년-학기 배치, 학점, 전필/전선/교필/교선, 선수과목)으로 변환한다.
연도별로 나눠 두면 앱에서 입학년도(학번)에 맞는 교육과정을 고를 수 있다.

변환: `python parse.py && python convert.py` → `src/data/curriculum.js` 갱신.
이 폴더의 PDF 원본은 git에 올리지 않는다 (.gitignore). 스크립트는 올린다.
