# 03. 챗봇 UI

> 목표: 페르소나 전환 + 채팅이 되는 화면 (LLM 연결 전, 더미 응답으로 동작 확인)
> 예상 소요: 반나절

---

## 화면 구성 (단일 페이지)

```
┌─────────────────────────────────────┐
│  동학 同學        [1학년][3학년][4학년] │  ← 헤더 + 페르소나 전환 탭
├─────────────────────────────────────┤
│  현재 프로필 카드                      │  ← 학년/관심분야/목표/이수학점 요약
├─────────────────────────────────────┤
│                                     │
│  채팅 메시지 영역 (스크롤)              │
│                                     │
├─────────────────────────────────────┤
│  [입력창.................] [전송]      │
└─────────────────────────────────────┘
```

## 작업 지시 (Cursor)

1. `PersonaSwitcher.jsx`: personas.json을 읽어 탭 3개 렌더. 선택된 페르소나는 상단 프로필 카드에 요약 표시 (학년, 관심분야, 목표, 이수학점/부족 요건)
2. `ChatWindow.jsx`:
   - 메시지 상태: `[{ role: 'user'|'assistant', content: string }]`
   - **페르소나 전환 시 대화 초기화** + 시스템 인사말 출력: "안녕하세요, {label}님! 무엇이 궁금한가요?"
   - 전송 시 일단 더미 응답 반환 (`"(LLM 연결 예정) 질문: ..."`)
   - 어시스턴트 메시지는 마크다운 렌더링 (`react-markdown` 설치)
3. 디자인 방향:
   - Tailwind만 사용, 컴포넌트 라이브러리 금지 (의존성 최소화)
   - 톤: 학교 느낌의 차분한 색 1개(예: 남색 계열)를 포인트로, 나머지는 흰/회색
   - 모바일 폭(390px)에서도 깨지지 않게 — 온라인 전시는 폰으로 보는 사람이 많음
4. 빠른 질문 버튼 3개를 입력창 위에 배치: "이번 학기에 뭘 해야 할까?", "졸업까지 뭐가 남았어?", "들을 만한 교양 추천해줘" → 클릭 시 해당 텍스트로 즉시 전송 (데모 때 오타 방지용)

## 완료 기준

- [ ] 페르소나 탭 전환 시 프로필 카드 내용이 바뀌고 대화가 초기화된다
- [ ] 메시지 입력 → 더미 응답이 채팅으로 표시된다
- [ ] 빠른 질문 버튼 3개가 동작한다
- [ ] 모바일 폭에서 레이아웃이 깨지지 않는다
