# 02. 데이터 구축 — 페르소나 & 지식베이스

> 목표: 데모의 재료가 되는 페르소나 3개 + 학사 지식 텍스트 완성
> 예상 소요: 3~4시간 (자료 수집 포함)
> **이 단계 품질이 데모 품질을 결정한다. 대충 넘기지 말 것.**

---

## A. 자료 수집 (사람이 직접, Cursor 아님)

1. 국립순천대학교 인공지능공학부(컴퓨터공학과) 홈페이지에서 다운로드:
   - 교육과정표 (학년·학기별 개설 과목)
   - 졸업요건 (총 이수학점, 전공/교양 영역별 요건, 영어성적, 졸업작품 등)
2. 교양 과목 목록 (수강신청 시스템 or 학사요람에서 영역별 대표 과목 20~30개면 충분)
3. **못 구하는 항목은 기억을 바탕으로 그럴듯하게 작성하되, 파일 상단에 `※ 데모용 샘플 데이터` 주석을 반드시 남긴다.** (심사 질의 시 "실서비스에서는 학과 제공 데이터로 교체" 답변)

## B. 지식베이스 작성 — `src/data/knowledge.js`

작업 지시 (Cursor):

```js
// 하나의 큰 템플릿 문자열로 export. 섹션 구분은 마크다운 헤더 사용.
export const KNOWLEDGE = `
# 인공지능공학부 교육과정 (데모용 샘플 데이터)
## 1학년
- 1학기: 프로그래밍기초(파이썬), 대학수학, ...
- 2학기: 자료구조입문, ...
## 2학년 ... (4학년까지)

# 졸업요건
- 총 이수학점: 130학점 이상
- 전공: XX학점 이상 / 교양: 영역별 요건 명시
- 공인영어성적: 토익 XXX점 이상 (또는 대체 요건)
- 졸업작품(캡스톤디자인) 이수 필수

# 교양 과목 목록 (영역별)
- 인문: ..., 예술: ..., 데이터/SW: ...

# 진로별 추천 로드맵 (요약)
- 클라우드/인프라 계열: 리눅스, 네트워크 과목 + 클라우드 자격증
- AI/데이터 계열: 머신러닝, 데이터엔지니어링 + 관련 공모전
`;
```

- 분량 가이드: 전체 3,000~6,000자. 너무 길면 토큰 낭비, 너무 짧으면 답변이 빈약해짐
- 수집한 실제 자료를 위 구조에 맞춰 채워 넣는 것이 Cursor의 일

## C. 페르소나 작성 — `src/data/personas.json`

```json
[

    "id": "freshman",
    "label": "1학년 김새내",
    "profile": {
      "grade": 1,
      "semester": "1학년 2학기",

      "goal": "미정",
      "completedCourses": ["프로그래밍기초"],
      "gradAudit": null
    }
  },
  {
    "id": "junior",
    "label": "3학년 박중견",
    "profile": {

      "gradAudit": { "totalCredits": 88, "missing": ["전공심화 6학점", "예술 교양 2학점"] }
```

- 각 페르소나의 `completedCourses`는 지식베이스의 교육과정표 과목명과 **정확히 일치**시킬 것 (LLM이 대조 가능해야 함)
- 4학년 페르소나의 missing에 "공인영어성적"이 반드시 포함되어야 함 → 데모의 .ics 장면과 연결됨
