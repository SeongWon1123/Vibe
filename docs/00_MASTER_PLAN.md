## 4. 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 프론트 | Vite + React + Tailwind CSS | 빠른 셋업, Cursor가 잘 다룸 |
| 백엔드 | Vercel Serverless Function (`/api/chat`) | API 키를 클라이언트에 노출하지 않기 위한 최소 서버 |
| LLM | OpenAI 호환 API (xAI Grok 또는 보유 키 아무거나) | `.env`의 `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`로 교체 가능하게 |
| 캘린더 | .ics 문자열 직접 생성 (라이브러리 불필요) | 표준 포맷, 클릭 시 폰/PC 캘린더에 바로 등록 |
| 배포 | Vercel | 온라인 전시용 공개 링크 필수 |
