# 06. 배포 & 데모 제작

> 목표: 누구나 접속 가능한 공개 링크 + 3분 데모 영상
> 예상 소요: 하루 (토 8/29)
> **배포를 오전에 먼저 한다. 영상은 배포된 사이트로 찍는다.**

---

## A. Vercel 배포 (오전)

1. Vercel 계정에 GitHub 저장소 연결 → Import
2. 환경변수 등록: `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL` (Production)
3. 배포 후 확인:
   - [ ] 공개 URL에서 채팅 정상 동작 (세 페르소나 모두)
   - [ ] 폰에서 접속해 .ics 다운로드 → 캘린더 등록까지 동작
   - [ ] 시크릿 창(비로그인)에서도 접속됨
4. **비용 가드**: LLM API 대시보드에서 사용량 한도/알림 설정. 온라인 전시 기간(8/31~9/4)에 불특정 다수가 호출하므로, `api/chat.js`에 간단한 안전장치 추가:
   - 요청당 `max_tokens` 900 유지
   - `messages` 배열 길이 20 초과 시 앞부분 잘라내기
   - (선택) 같은 IP 분당 10회 제한 — 시간 남으면

## B. 데모 영상 (오후)

마스터 플랜 7절 시나리오대로 촬영. 체크:

- [ ] 화면 녹화는 배포된 URL로 (localhost 금지 — 주소창이 보이게)
- [ ] 페르소나 3연속 질문 장면: 답변 로딩이 길면 편집으로 점프컷
- [ ] .ics 장면은 **폰 캘린더에 일정이 뜨는 실물 화면**으로 마무리 (임팩트 최대 지점)
- [ ] 마지막 슬라이드: "학생에게는 4년을 함께 크는 AI 선배, 조교에게는 반복 상담을 덜어주는 조수" + 향후 확장 3줄(학사시스템 연동, 프로필 자동 학습, 전 학과 확대)
- [ ] 3분 이내, 1080p, 자막 또는 자료화면으로 소리 없이도 이해되게

## C. 소개 자료 (접수 양식용)

scnuai.com 접수 양식에 들어갈 텍스트 미리 작성 (`docs/submission_text.md`):

- 서비스명 / 한 줄 소개
- 문제 정의 (3줄): 정보 격차, 분산된 학사 정보, 조교 반복 상담
- 핵심 기능 (3개): 성장형 프로필 상담 / 졸업요건 체크 / 공지→캘린더
- 기술: LLM API + RAG 방식 지식베이스 + .ics 표준
- 데모 링크 + 영상 링크
- ※ 개인정보 관련 한 줄: "데모는 가상 학생 데이터 사용, 실서비스 시 본인 인증 및 학사시스템 연동 필요"

## 완료 기준

- [ ] 3분 영상 완성 (파일 + 유튜브 일부공개 업로드)
