# 접수 양식 초안

- 서비스명: 동학(同學, DongHak)
- 한 줄 소개: 4학년이 되어서야 알게 되는 것들을, 1학년부터 함께 성장하며 미리 알려주는 AI 학사 에이전트

## 문제 정의
학사 정보는 학년·이수 이력에 따라 달라지는데, 공지·요람·조교 상담에 흩어져 있다. 저학년은 같은 질문을 해도 자기 상황에 맞는 답을 받기 어렵고, 고학년이 되어서야 영어성적·졸업작품 공백을 알게 된다. 조교는 같은 상담을 반복한다.

## 핵심 기능
1. 성장형 프로필 상담 — 1·3·4학년 페르소나에 따라 같은 질문에도 다른 조언
2. 졸업요건 체크 — 이수 학점과 부족한 요건을 대조
3. 공지 → 캘린더 — 붙여넣은 공지에서 일정을 뽑아 .ics로 저장

## 기술
LLM API + 학사 지식베이스(프롬프트 주입) + .ics 표준. 데모는 가상 학생 데이터 사용.
