## 상세 설명 (양식에 설명란이 있으면 사용)

### 문제
학사 정보는 학년·이수 이력에 따라 달라지는데, 공지·학사요람·조교 상담에 흩어져 있다. 저학년은 같은 질문을 해도 자기 상황에 맞는 답을 받기 어렵고, 고학년이 되어서야 영어성적·졸업작품 공백을 알게 된다. 조교는 같은 상담을 반복한다.

### 해결
동학은 학생이 직접 넣은 학년·관심·목표·학점·시간표를 바탕으로 답하는 AI 학사 메이트다. 1~2학년에게는 관심 분야를 넓히는 쪽으로, 3~4학년에게는 자격증·인턴·포트폴리오·취업 준비 쪽으로 방향을 잡아 주고, 상담에서 드러난 관심 키워드를 쌓아 가며 학생을 점점 더 잘 알게 된다.

1. **성향·관심 파악** — 온보딩(학년·관심·목표)과 상담 키워드로 프로필이 자라고, 학년에 맞는 '다음 한 걸음'을 제안
2. **학점 관리 + 시간표** — 이수 학점을 직접 입력하고 시간표를 넣으면 이번 학기 과목·학점이 자동 반영, 졸업 130학점까지 남은 학점·전공·교양 계산
3. **공지 → 캘린더** — 붙여 넣은 공지에서 접수 마감만 뽑아 .ics로 저장, 하루 전 알림
4. **선배 / 메이트 모드** — 먼저 겪은 선배의 피드백 톤과 같이 학기를 굴리는 친구 톤 중 선택. 물어본 것에만 답한다
5. **4학년 포트폴리오 체크리스트** — GitHub 정리부터 이력서 초안까지

### 기술
Vite + React 19 (모바일 앱형 UI) · 프로필·학점·시간표는 브라우저 localStorage에만 저장 · Vercel Serverless Function이 OpenAI 호환 LLM(OpenRouter)을 프록시 · 학사 지식베이스는 시스템 프롬프트 주입 · .ics 표준으로 캘린더 등록 · API 키는 서버에만 보관, IP당 분당 10회 제한

※ 교육과정·학사일정·공지는 샘플이며, 학점·시간표는 사용자가 직접 입력합니다. 실서비스 시 본인 인증 및 학사시스템 연동이 필요합니다.
