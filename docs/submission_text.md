## 상세 설명 (양식에 설명란이 있으면 사용)

### 문제
학사 정보는 학년·이수 이력에 따라 달라지는데, 공지·학사요람·조교 상담에 흩어져 있다. 저학년은 같은 질문을 해도 자기 상황에 맞는 답을 받기 어렵고, 고학년이 되어서야 영어성적·졸업작품 공백을 알게 된다. 조교는 같은 상담을 반복한다.

### 해결
동학은 한 학생(최성원)의 1~4학년을 옆에서 보는 AI 선배다. 같은 질문 "이번 학기에 뭘 해야 할까?"에도 학년·이수과목·목표에 따라 다른 답을 준다.

1. **성장형 프로필 상담** — 1·2·3·4학년 프로필에 따라 같은 질문에도 다른 조언
2. **졸업요건 체크** — 이수 학점과 아직 안 닫힌 요건을 대조해 빈칸부터 알려줌
3. **공지 → 캘린더** — 붙여 넣은 공지에서 접수 마감만 뽑아 .ics로 저장, 하루 전 알림

### 기술
Vite + React 19 (모바일 앱형 UI) · Vercel Serverless Function이 OpenAI 호환 LLM(OpenRouter)을 프록시 · 학사 지식베이스는 시스템 프롬프트 주입 · .ics 표준으로 캘린더 등록 · API 키는 서버에만 보관, IP당 분당 10회 제한
